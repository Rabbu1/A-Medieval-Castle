“A Medieval Castle” is a dynamic 3D castle scene created using Three.js, designed to immerse users in a medieval setting with realistic visual and interactive elements. The castle is constructed with tall, textured stone walls that cast shadows for depth and authenticity. A functional drawbridge, textured with wood, animates smoothly as it raises and lowers based on user input or predefined timing. The scene's realism is enhanced with lighting and sky effects. The sky color shifts seamlessly throughout the day, transitioning from bright blues to warm sunset hues, and eventually to night tones, creating a sense of time passing. A moving directional light simulates the sun's path across the castle, generating natural lighting and shadows throughout the day. The camera is equipped with OrbitControls, allowing users to explore the castle from all angles with smooth mouse navigation, while keyboard controls offer manual adjustments for a more personalized viewing experience. By combining custom shaders, texture mapping, dynamic lighting, and interactive animations, the project brings the medieval castle to life in an immersive 3D environment.
